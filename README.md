# mellowbikers-astro

De site van Mellowbikers. Twee projecten:

- **repo-root** — de Astro-site die nu op mellowbikers.nl draait
- **`payload/`** — de herbouw op Payload CMS die Astro gaat vervangen

Begin bij [HANDOVER.md](HANDOVER.md) voor de stand van zaken en de
volgende stappen, en [CLAUDE.md](CLAUDE.md) voor de afspraken die niet uit
de code blijken. De handleiding van het Payload-project staat in
[payload/README.md](payload/README.md).
